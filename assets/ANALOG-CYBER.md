# Analog/cyber faceplate

`analog-cyber-faceplate.png` is an original orthographic brushed petrol-black anodized aluminum surface texture with subtle mint-cyan (`#83D4D0`) and warm copper-amber (`#D7AC7B`) edge undertones and dark vignetted edges. It is embedded in the plugin binary via `juce_add_binary_data`; all controls, labels, waveforms, piano roll notes, and animations are rendered live by the JUCE editor.
